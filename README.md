# SAT Reading and Writing Sprint

A single-page study site for the whole SAT Reading and Writing section:

- **Grammar:** a 60-second method, lessons for every rule, and shortcuts from the answer choices.
- **Reading:** a four-step routine (Job, Chunk, Say, Check), long sentences and long passages taken apart, and a goal-first method for notes questions.
- **Drills** for the slow steps, and **timed practice** on real questions from College Board's SAT Suite Question Bank with College Board's answers.

Open `index.html`, or visit the GitHub Pages site once Pages is turned on (Settings → Pages → Deploy from a branch → `main`, `/ (root)`).

Progress is saved in your browser only.
